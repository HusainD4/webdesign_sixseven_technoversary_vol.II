## Deskripsi Website

**NUSA (Puncak Cerita Nusantara)** merupakan platform ensiklopedia digital bertema eksplorasi alam yang menyajikan informasi dan pengetahuan mengenai pegunungan, gunung, dan bukit yang tersebar di seluruh wilayah Indonesia.

NUSA hadir untuk merangkai keindahan, pengetahuan, dan kisah dari pegunungan Nusantara dalam satu ruang digital. Platform ini dirancang sebagai sumber informasi geografis dan ekologis yang membantu pengguna mengenal lebih dekat kekayaan bentang alam Indonesia.

### Informasi yang Disajikan

* **Informasi Gunung dan Bukit:** Nama gunung atau bukit beserta deskripsi dan informasi umum.

* **Informasi Ketinggian:** Data ketinggian gunung atau bukit dalam satuan meter di atas permukaan laut (mdpl).

* **Lokasi Geografis:** Informasi wilayah administratif tempat gunung berada.

* **Koordinat Geografis:** Titik koordinat lokasi gunung untuk membantu identifikasi posisi geografis.

* **Ekologi Setempat:** Informasi mengenai kondisi lingkungan dan ekosistem di sekitar kawasan pegunungan.

* **Informasi Cuaca:** Menampilkan kondisi cuaca terkini Gunung Rinjani, meliputi suhu udara dan kecepatan angin.

## Fitur dan Elemen Antarmuka

Website NUSA dibangun dengan pendekatan desain modern, minimalis, dan bernuansa alam dengan elemen antarmuka berikut:

* **Navigasi Utama:** Bar horizontal dengan ikon dan label untuk akses cepat ke halaman **Beranda**, **Jelajah**, **Tentang**, dan **Kontak**.

* **Hero Section:**

  * Foto pegunungan yang diselimuti awan sebagai latar penuh layar (*full-screen*).

  * Label *"Puncak Cerita Nusantara"*, judul utama, dan deskripsi singkat NUSA.

  * Tombol aksi utama (*Call-to-Action*): **"Jelajahi peta"** dan **"Kenali alam Indonesia"**.

* **Kontrol Tema:** Tombol ikon matahari di sisi kanan atas sebagai pengubah tema tampilan (Mode Gelap & Mode Terang).

* **Penanda Jelajah:** Elemen penanda vertikal di sisi kanan halaman disertai informasi koordinat geografis di bagian kanan bawah area hero.

* **Akses Bantuan:** Tombol **"Teman Jelajah"** di sudut kanan bawah untuk bantuan atau panduan pengunjung.

## Struktur Halaman

1. **Beranda** — Pengenalan NUSA, gambaran visual utama, dan ajakan untuk mulai menjelajah.

2. **Jelajah** — Area peta interaktif dan katalog pegunungan Nusantara.

3. **Tentang** — Informasi mengenai tujuan, latar belakang, dan prinsip NUSA.

4. **Kontak** — Kanal komunikasi atau formulir pesan.

5. **Teman Jelajah** — Fitur bantuan atau panduan interaktif bagi pengunjung.

## Prinsip Pengembangan

Prinsip sederhana yang membentuk cara NUSA bercerita tentang alam:

### 01. Berangkat dari Data

Informasi geografis disajikan dengan konteks yang jelas, satuan yang mudah dibaca, dan rujukan yang dapat ditelusuri.

Cerita tentang bentang alam berjalan bersama kepedulian pada ekosistem, keselamatan pengunjung, dan masyarakat setempat.

### 03. Belajar Bersama

Atlas ini menjadi titik awal untuk rasa ingin tahu, percakapan, pendidikan, dan kontribusi pengetahuan yang bertanggung jawab.

Tata letak dirancang responsif untuk ukuran layar desktop, tablet, dan ponsel dengan tetap memperhatikan kontras warna dan keterbacaan teks.

## Petunjuk Instalasi dan Menjalankan Project

Ikuti langkah-langkah berikut untuk mengunduh, menginstal, dan menjalankan project NUSA di lingkungan lokal.

### 1. Persyaratan

Pastikan perangkat telah memasang:

* [Node.js](https://nodejs.org/) (sudah termasuk npm)
* [Git](https://git-scm.com/)

### 2. Clone Repository

Buka terminal, lalu clone repository NUSA:

```bash
git clone https://github.com/HusainD4/webdesign_sixseven_technoversary_vol.II.git
```

### 3. Masuk ke Folder Project

Project website berada di dalam folder `webdesign_sixseven_technoversary_vol.II`. Masuk ke folder tersebut:

```bash
cd webdesign_sixseven_technoversary_vol.II
```
langkah selanjutnya

```bash
cd webdesign_sixseven_technoversary_vol.II
```
### 4. Install Dependencies dan Jalankan

Instal dependencies:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buka alamat lokal yang ditampilkan di terminal, biasanya:

```text
http://localhost:5173
```

Untuk memeriksa build produksi (opsional), jalankan dari folder project:

```bash
npm run build
```
